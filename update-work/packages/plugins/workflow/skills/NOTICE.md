# Skills in this folder

Every skill folder here is copied unchanged from
[addyosmani/agent-skills](https://github.com/addyosmani/agent-skills) (`skills/`), commit `39b723c` (2026-11-13).

They are Addy Osmani's work under the MIT License; the full license text is in [LICENSE](LICENSE) in this folder.
Nothing in these folders was written or edited for this plugin, so they can be refreshed by copying the upstream
`skills/` folder over this one again.

The stage order the plugin uses (`../prompts.ts`) follows that project's lifecycle (Define, Plan, Build, Verify,
Review, Ship). The test-first and root-cause-debugging loops are also described by
[obra/superpowers](https://github.com/obra/superpowers) (MIT), and the security step follows the
[OWASP Developer Guide](https://devguide.owasp.org/) and the OWASP Top 10.
